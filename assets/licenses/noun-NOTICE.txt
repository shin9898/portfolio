These baseball line-art marks are pasted as a repeating wallpaper
(貼り付け画像 / pattern), not as the four role UI marks.

Download filenames in noun-source/ and wallpaper/glyphs/ do not match
the depicted marks. Glyphs are the same pixels with the watermark strip
cropped (credit is in the site footer instead). No tracing or redrawing.
reference-wallpaper.png is a vibe reference only and is not a site asset.

Displayed wallpaper:
  assets/wallpaper/noun-baseball-tile.png
  900×600 seamless diamond tile (period 300, stroke unchanged).
  Both diamond sublattices filled — 12 unique cells, all 7 glyphs.
  Glyphs sit only in the white CELL faces (not on stroke crossings).
  Inscribed in the white diamond (L1 mask) and rotated 45° with the lattice.
  Edge-centered cells wrap so the tile repeats without a blank.
  CSS origin 0 0, background-attachment / position fixed.
