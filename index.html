P.06 — AI ハーネス

役割を分ける。人が止まる

自己PR「速さは AI、責任は人」と同じ。PDF と個人リポ。

  • 役割を分ける

    設計・実装・レビューを、同じ手が兼ねない。

    Claude が設計 → Codex が実装 → CodeRabbit がレビュー。同一セッションが実装者と最終 reviewer を兼ねない workbench: skills/route-dev-workflow

  • 人が止まれる

    CS の返信は案まで。顧客の声の抽出は読み取り専用。本番 DB は書かない。PdM では AI 提案を人がゲート。

    PII 混入は failClosed。キルスイッチ表あり workbench: my-copy/scripts/pii_guard.py

  • 判断を残す

    課題設定・レビュー・テスト・CI・リリース判定は、人が検証できる形に。

    一次レビュアーの見逃しは、別モデルで月次サンプリング。同じモデルの再実行は「ブレ」でしかない、と明記 workbench: review-blindspot-audit

ハーネスは Claude / Codex / Cursor で共用。ツール名の羅列はしない。
